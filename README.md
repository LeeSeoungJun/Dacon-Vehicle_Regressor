# 전기차 가격 예측

원본 개인 프로젝트의 분석 흐름과 3개 트리 모델을 유지하면서 평가·전처리·실행 오류를 수정했습니다.

## 작업 내용

- 주행거리·배터리 분포 확인, 모델별 중앙값으로 배터리 결측 대체
- 기존 3표준편차 이상치 처리, 표준화, 원핫 인코딩
- OLS와 기존 주행거리 제거 과정 유지 (OLS에서만 중복 정보 제거)
- Random Forest, XGBoost, LightGBM별 올바른 예측값으로 RMSE 계산
- 8:2 검증을 전처리보다 먼저 수행하고 학습 기준을 검증·제출 자료에 적용
- 기존 최종 LightGBM으로 전체 자료 재학습 후 result13.csv 생성

## 실행

`pip install -r requirements.txt` 후 [원본 흐름을 유지한 노트북](전기차가격예측.ipynb)을 처음부터 실행합니다.
원본 train.csv, test.csv, sample_submission.csv는 변경하지 않았습니다.
검증 성능은 model_comparison.csv에 저장됩니다. 기본 전처리 방식·모델과 그래프는 원본에 기반합니다.

## 성과와 한계

기존 기재 대회 기록: 74위 / 1,314명(상위 5.6%). 새 로컬 검증 점수와 구분합니다.
무작위 단일 검증이며 신규 차종·미래 가격에 대한 일반화를 검증하지 않았습니다.
검증 점수로 모델을 비교했으므로 독립 최종 테스트의 점수로 표현하지 않습니다.
주행거리 제거는 원본 접근을 유지한 것이며, 트리 모델에서 불필요한 변수임을 증명하지 않습니다.
