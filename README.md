# 데이콘 전기차 가격 예측 해커톤
**74위 / 1,314명 참여 · 상위 5.6%**

전기차의 다양한 특성 데이터를 활용해 **차량 가격을 예측하는 회귀 프로젝트**입니다. 데이터 전처리와 OLS 분석을 진행하고, Random Forest·XGBoost·LightGBM의 예측 성능을 비교했습니다.

[Dacon 대회 페이지](https://dacon.io/competitions/official/236424/overview/description) · [분석 노트북](전기차가격예측.ipynb)

## 프로젝트 목표

전기차의 주요 특성과 가격 간 관계를 분석하고, 머신러닝 모델을 활용해 가격을 예측하는 것을 목표로 했습니다. 제조사·모델·차량상태·배터리용량·구동방식·주행거리·보증기간·사고이력·연식 정보를 사용했으며, 예측 대상은 `가격(백만원)`입니다.

## 분석 과정과 주요 선택

### 1. 데이터 확인과 전처리

학습 데이터 7,497행을 확인하고, 주행거리와 배터리용량의 분포를 시각화했습니다. 검증 정보가 전처리에 들어가지 않도록 **학습·검증 데이터를 먼저 8:2로 분리**한 뒤 학습 데이터에서 정한 기준을 검증·제출 데이터에 적용했습니다.

| 처리 | 적용 방식과 의미 |
| --- | --- |
| 배터리용량 결측값 | 같은 차량 모델의 중앙값으로 채우고, 대체가 어려우면 전체 학습 데이터의 중앙값을 사용했습니다. 차종별 대표값을 우선 반영하는 방식입니다. |
| 이상치 기준 | 차량상태·구동방식·사고이력별 가격에 평균 ±3표준편차 기준을 순서대로 적용했습니다. 저장된 실행에서는 실제 제거된 행이 없었습니다. |
| 범주형 변수 | `One-Hot Encoding`으로 모델·제조사·차량상태·구동방식·사고이력을 숫자 크기의 순서 없이 표현했습니다. |
| 수치형 변수 | `StandardScaler`로 척도를 맞췄습니다. 기존 분석 흐름을 유지한 처리이며, 트리 모델에 필수적인 단계는 아닙니다. |

중앙값 대체와 3표준편차 기준을 다른 방법과 비교한 실험은 기록되어 있지 않습니다.

### 2. OLS 분석과 변수 선택

OLS로 변수의 계수와 유의확률을 확인했습니다. 제조사와 모델의 중복 정보 및 더미 변수의 완전 공선성을 줄이기 위해 **OLS에서만 제조사 더미와 범주별 기준 더미를 제외**했습니다.

주행거리의 p-value는 **0.293**이었고, 노트북에서는 유의하지 않은 변수로 판단해 이후 모델 입력에서 제거했습니다. 다만 OLS의 유의확률만으로 트리 모델에서의 필요성을 판단할 수는 없으므로, 주행거리 포함·제외에 따른 성능 비교는 추가 검증 과제로 남아 있습니다.

### 3. 모델 비교와 설정

같은 학습·검증 분할에서 세 모델을 비교했습니다.

| 모델 | 명시한 설정 |
| --- | --- |
| Random Forest | `random_state=3000, n_jobs=4` |
| XGBoost | `random_state=5024, n_jobs=4` |
| LightGBM | `random_state=3000, n_jobs=4, verbosity=-1` |

데이터 분할은 `test_size=0.2, random_state=3000`을 사용했습니다. 시드는 재현성을 위한 설정이고, `n_jobs=4`는 병렬 작업 수, `verbosity=-1`은 LightGBM의 로그 출력 설정입니다.

8:2 비율과 시드 값은 기존 설정을 유지했습니다. 해당 값의 비교·탐색 기록은 없으며, 트리 수·깊이·학습률 등은 별도 지정 없이 라이브러리 기본값을 사용했습니다.

## 평가 결과

평가 지표는 **RMSE (Root Mean Squared Error)**이며, 단위는 백만원입니다. 값이 낮을수록 예측 오차가 작습니다.

| 모델 | 검증 RMSE(백만원) |
| --- | ---: |
| Random Forest | 1.367719 |
| XGBoost | 1.400942 |
| **LightGBM** | **1.344152** |

수치는 현재 [노트북](전기차가격예측.ipynb)과 [model_comparison.csv](model_comparison.csv)에 저장된 결과를 소수점 여섯 자리로 표시했습니다. **이 검증 분할에서는 LightGBM이 가장 낮은 RMSE**를 기록했습니다.

최종 제출 모델은 기존 흐름대로 LightGBM을 사용했습니다. 전처리된 학습·검증 데이터를 합쳐 다시 학습한 뒤 `result13.csv`를 생성하며, 제출 ID 순서·행 수·예측값의 유한성을 확인합니다. 전처리 기준은 최초 학습 부분에서 정한 값을 유지합니다.

**대회 성과는 74위 / 1,314명, 상위 5.6%**입니다. 위 표는 현재 저장된 로컬 검증 결과로, 대회 리더보드 점수와 구분합니다.

## 한계와 개선 방향

현재 결과는 한 번의 무작위 검증 분할에 기반합니다. 교차검증으로 모델 비교의 안정성을 확인하고, 주행거리 제거와 전처리의 개별 효과를 비교할 필요가 있습니다. 하이퍼파라미터 탐색과 신규 차종·미래 시점에 대한 검증은 수행하지 않았습니다. 또한 의존성 버전이 하한으로 지정되어 있어 실행 환경에 따라 결과가 달라질 수 있습니다.
